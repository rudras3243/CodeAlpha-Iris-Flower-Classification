# Iris Flower Classification Project

This is a complete assignment project using the supplied Iris.csv dataset.

Files:
- Iris.csv - dataset
- iris_classification.py - main ML program
- Project_Report.md - ready-to-use project report
- model_comparison.txt - model accuracy comparison
- petal_scatter.png - visualization
- requirements.txt - Python libraries

Main result: SVM (RBF) achieved 96.67% accuracy on the 20% test split.

Run:
pip install -r requirements.txt
python iris_classification.py
